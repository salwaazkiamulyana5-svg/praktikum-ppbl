# Nusantara Cerdas Mobile — Modul 5
Pengembangan lanjutan proyek Modul 4 untuk Bagian G Soal 1. State bersama dikelola menggunakan `flutter_bloc` dan Cubit: `FavoritCubit` untuk layanan favorit dan `PengajuanCubit` untuk daftar pengajuan. Status pengiriman pada halaman rincian tetap menggunakan `setState()` sesuai ketentuan modul.

Jalankan:
1. `flutter pub get`
2. `flutter run` atau `flutter run -d chrome`

Kerangka navigasi bernama dan halaman yang telah dibuat pada modul sebelumnya dipertahankan.
