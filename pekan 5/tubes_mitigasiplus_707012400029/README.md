# Mitigasi Plus — Modul 5 Soal 2
Lanjutan proyek Modul 4. Data catatan kesiapsiagaan bersama dikelola oleh `KesiapsiagaanCubit` dan ditampilkan pada halaman Cek Kesiapsiagaan serta Statistik. State lokal pilihan risiko dan checkbox tas siaga tetap menggunakan `setState()`.

Jalankan:
1. `flutter pub get`
2. `flutter run` atau `flutter run -d chrome`
